# Marketing Vehicles — AKAI

Planificacion de vehiculos estrategicos que llevan la estrategia al contenido.

Esto incluye influencer marketing, UGC, affiliate marketing, partnerships y colaboraciones.

## Regla

Aqui se planifica:

- quien participa;
- costo;
- brief;
- entregables;
- fechas;
- estado;
- aprobaciones;
- derechos de uso;
- links/IDs de Jockey cuando el contenido final este aprobado.

Los archivos finales de foto/video no viven aqui. Viven en Jockey.
